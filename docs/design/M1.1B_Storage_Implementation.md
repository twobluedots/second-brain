### 2. Database Patterns
- **Row Factories**: `sqlite3.Row` → `dict` conversion for UI consumption
- **Context Managers**: `@contextmanager` with auto-commit/rollback
- **Soft Delete**: `deleted_at IS NULL` filtering with audit trail
- **Timestamps**: ISO 8601 text format with UTC explicit (Z suffix)

### 3. Dual Storage Strategy
- **SQLite**: Source of truth for structured data
- **ChromaDB**: Search index only, graceful degradation if unavailable
- **Bridge**: ChromaDB `ids` field connects to SQLite `id` (no redundancy)
- **Consistency**: SQLite as primary, ChromaDB best-effort with repair mechanism

## Data Flow

### Saving
```
Entry dict → save(entry)
  ├─ Generate ID (UUID)
  ├─ Extract/normalize fields  
  ├─ INSERT into SQLite (with transaction)
  └─ ADD to ChromaDB (document + metadata)
```

### Querying
```
Query → get_by_category() / get_recent()
  └─ SELECT from SQLite with soft-delete filter
  └─ Convert Row → dict + parse JSON fields
  └─ Return to UI
```

### Searching  
```
Text query → search(query)
  ├─ Query ChromaDB (semantic matching)
  ├─ Extract entry IDs from results
  └─ Fetch full entries from SQLite
  └─ Return structured results
```

## Error Handling & Consistency

### Consistency Strategy
- **SQLite = Source of Truth**: Primary storage for all data
- **ChromaDB = Best Effort**: Search index with graceful fallbacks
- **Natural Protection**: Search → fetch pattern filters deleted entries
- **Repair Mechanism**: Planned daily sync job to fix inconsistencies

### Error Scenarios
| Case | Behavior | Mitigation |
|------|----------|------------|
| SQLite ✅ → ChromaDB ❌ | Entry saved, warning printed | Search index stale but data safe |
| SQLite update ✅ → ChromaDB update ❌ | Data updated, search stale | Repair mechanism will fix |
| SQLite delete ✅ → ChromaDB delete ❌ | Entry soft-deleted | get_by_id() filters it out naturally |

## Key Improvements from Refactoring

### Context Manager Enhancement
Moved from functional to idiomatic Python pattern:

**Before:**
```python
with self._get_conn() as conn:
    conn.execute(...)
    conn.commit()  # Manual commit everywhere
```

**After:**
```python
@contextmanager
def _connect(self):
    conn = sqlite3.connect(str(self.db_path))
    conn.row_factory = sqlite3.Row
    try:
        yield conn
        conn.commit()  # Auto-commit on success
    except Exception:
        conn.rollback()  # Auto-rollback on exception
        raise
    finally:
        conn.close()
```

**Benefits:**
- ✅ Transactional safety (impossible to have partial writes)
- ✅ Exception-safe (auto-rollback if anything fails)  
- ✅ Cleaner code (no manual commits scattered)
- ✅ Pythonic (follows language conventions)
